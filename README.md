# Jonathan Oktaviano Frizzy

Engineer and open-source builder working across intelligent systems, embedded software, optimisation, and practical engineering tools.

I enjoy turning complex technical ideas into small, inspectable systems: a model with explicit assumptions, an interface that is easy to test, and documentation that helps the next engineer reproduce the result.

## Selected work

- [RuteHijau](https://github.com/robotjaol/rute-hijau) — capacity-aware waste-collection route optimisation with measurable fuel and CO₂ impact.
- [Factory Power Engineering Lab](https://github.com/robotjaol/factory-power) — screening-level industrial load and reliability simulations.
- [Vision Transformer Study](https://github.com/robotjaol/vit) — readable ViT implementations and a learning notebook.
- [AI CAN Bus Reverse Engineering](https://github.com/robotjaol/AI-CAN-Bus-Reverse-Engineering) — a research scaffold for discovering vehicle telemetry signals.
- [Protocol Debugger GUI](https://github.com/robotjaol/debugger_gui) — a desktop workbench for TCP, UDP, UART, and CAN experiments.
- [PCB Ruler](https://github.com/robotjaol/ruler) — a KiCad-based hardware reference design with manufacturing outputs.

## Engineering principles

- Make assumptions, units, and safety boundaries visible.
- Prefer reproducible experiments over unexplained results.
- Keep interfaces small and components replaceable.
- Treat documentation, tests, and operational constraints as part of the design.
- Share useful building blocks without exposing confidential project details.
